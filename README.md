# מוסך מוטי — עותק נקי ועריך

האתר החי: https://smai-sentinel.github.io/moti-garage-clean/

פרויקט React + TypeScript + Vite. העותק אינו כולל מיתוג, קישורים או סימן מים של Bolt.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בניית גרסת הפצה

```bash
npm run build
```

הקבצים המוכנים לפריסה נוצרים בתיקייה `dist/`.
